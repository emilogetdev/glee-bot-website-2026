Last updated: October 30, 2026

Important draft notice: This is not yet a verified description of GLEE's data practices. Before relying on it, check the bot source code, database, logs, hosting provider and enabled Discord features, then update this page so every statement is accurate.

1. Scope

This page concerns the GLEE Discord bot project. Discord separately processes information under its own privacy policy and terms.

2. Information the bot may process

Depending on enabled features and implementation, GLEE may receive or process Discord identifiers (such as server, channel or user IDs), command and interaction data, server settings, and information included in actions that invoke a feature. Verify which information is actually collected or stored.

3. Purposes

Information should only be processed as needed to operate requested bot features, maintain configuration, protect the service, troubleshoot issues or meet legal obligations. Update this section to match actual use.

4. Storage, providers and retention

The project operator must document the actual hosting, database, logging and backup providers, what information each receives, where it is stored and how long it is retained. These details are not known from this template and must be completed accurately.

5. Sharing

Identify relevant service providers and any other recipients once the actual hosting and data flows have been checked. Do not publish assumptions as facts.

6. Data requests and deletion

Document a working process for access or deletion requests, including any limits caused by backups or legal requirements. Use an official GLEE project support channel if available. Do not promise deletion until a process exists.

7. Security and updates

Reasonable safeguards should be used to protect information, but no online service can guarantee absolute security. Update this policy whenever features, data practices or providers change.
